📋 주제 제안 배경 및 개요

학생의 학교 교육과정에서 '인공지능윤리' 과목이 미개설된 점을 보완하기 위한 전략적 주제입니다. 단순히 코딩 기술을 나열하는 것을 넘어, 자율주행 사고 데이터(Trolley Problem Dataset)를 활용하여 의사결정 트리(Decision Tree)가 학습 데이터의 편향을 어떻게 재생산하는지 분석하는 프로젝트를 수행하세요. 이는 공학적 역량과 인문학적 소양을 동시에 보여줄 수 있는 강력한 스토리텔링이 됩니다.

🚀 활동 추천 방향

  1. Kaggle 등의 오픈 데이터셋 플랫폼에서 자율주행 관련 윤리 데이터 확보
  2. Python Scikit-learn 라이브러리를 활용하여 간단한 분류 모델 구축
  3. 특정 인종/성별에 따라 모델의 판단이 달라지는 '편향성(Bias)' 시각화 리포트 작성
📚 권장 탐구 도서
  • 수학의 쓸모 (닉 폴슨) - AI 알고리즘의 본질 이해
  • 대량살상 수학무기 (캐시 오닐) - 알고리즘 공정성
  • 알고리즘이 욕망하는 것들 (에드 핀)
